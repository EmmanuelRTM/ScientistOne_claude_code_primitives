# Seed papers & notes

Drop seed material for the Problem Investigator here: markdown/text notes
about relevant papers, extracted PDF text, or your own research notes.

In `--offline` runs (or when web access fails) this directory is the ONLY
literature source, so include for each paper at least: title, authors, year,
venue, and a factual summary of the findings. One file per paper is easiest
for the investigator to index.

Files ending in `.md` or `.txt` are read; the three `example-*.md` files ship
with the repo so the offline demo works out of the box — delete them for real
runs on other topics.
